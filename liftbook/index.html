Liftbook

Workout tracking without distractions.

Liftbook is a simple workout tracker built for people who want to log training without distractions. Record exercises, sets, reps, weights, personal records, and workout notes in a fast, local-first app designed to work offline. Track your progress over time, review workout history, build reusable templates, and keep your training data on your own device.

Tech stack

Built with a modern web-to-Android stack

Frontend

React, TypeScript, and Vite

Liftbook is built with React, Vite, and TypeScript for a fast, responsive interface and an efficient development workflow.

UI

Tailwind CSS and shadcn/ui

The app uses a lightweight component-driven UI stack focused on clean structure and fast interaction.

Android

Capacitor packaging for mobile delivery

The Android build is packaged through Capacitor while workout data remains local on the device through IndexedDB and browser storage.

Data handling

Local-first storage with import and export support

Stored on device

Liftbook currently stores workout data locally using IndexedDB for workouts, templates, and records, plus localStorage for active session state and preferences.

Portable data

The app supports local JSON export and import so users can move or back up their training history manually.
